## 使い始める3ステップ

1. 上のZIPを保存し、右クリックして **「すべて展開」** します。ZIPの中から直接起動せず、フォルダーごと展開してください。
2. 展開した **`MamoriToolbox`** フォルダーの **`START.html`** を、会社で許可されたEdge・Chrome等のブラウザーで開きます。
3. 初回は各画面の **「架空例」** から試します。画面上部の **「手順書を開く」** で、詳しい操作と保存方法を確認できます。

通常操作にアプリのインストール、Python、Node.js、会員登録、支払いは不要です。入力は自動保存されません。必要な結果は各画面の保存ボタンで保存し、保存先で内容を確認してください。

## 5つの点検機能

| 機能 | できること | できないこと |
|---|---|---|
| 入口・認証点検 | VPNやクラウド等の管理情報を台帳にし、改善候補を整理 | 接続先へのネットワーク走査、設定の自動修正 |
| Windows点検 | 架空結果または承認済み収集結果のJSONを表示 | 感染の判定、全アプリの脆弱性診断、実機検証済みの保証 |
| 不審URL点検 | リンクを開かず、実際のホスト名や紛らわしい表記を確認 | リンク先の内容や転送先の確認、安全性の証明 |
| AI送信前点検 | 一部の機密情報候補と指定語句を検出し、伏せ字案を作成 | 完全匿名化、外部送信許可の判断 |
| 復旧の備え点検 | バックアップの備えと目標との差を整理。2ファイルのSHA-256照合 | バックアップ作成、復元そのもの、システム全体の復旧証明 |

## 検証範囲と制限

判定・入力処理等の自動テスト113件、Chromiumのオフライン画面試験65件を再実行し、成功しています。種類が異なるため、侵入テストや企業向け認証の件数として合算しません。

検証環境では `file://` の直接起動が管理ポリシーで拒否されたため、画面試験はHTMLをテスト用ブラウザーのDOMへ読み込んで実施しました。**WindowsのEdge／Chrome、Mac、iPhone Safari、企業の管理端末での直接起動・動作は未検証です。** iPhone対応を保証していないため、まずPCでの試用を前提にしてください。

ファイル照合の共通処理はNodeの実Web Cryptoで確認しています。画面の照合成功系には試験用の代替処理を使っており、この代替処理は配布版に含めていません。実ブラウザーの暗号機能が利用できない環境では、比較せずにエラーを表示します。

Windows実機試験、電子署名、第三者コード・脆弱性レビュー、ウイルススキャンは未完了です。警告や組織の保護設定を解除・回避しないでください。詳しくは同梱の `CHECKS_AND_LIMITS.txt` をお読みください。
