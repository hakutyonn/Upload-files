# 守りの道具箱

AI業務改善ラボ / 白鳥 裕児が提供する、個人・法人向けの無料セキュリティ点検ツール集です。

本体、結果の表示・保存、基本手順は無料です。会員登録、カード情報、有料教材の購入は必要ありません。

## 検証版について

現在の版は `0.1.1-preview`（ツール本体は `0.1.0-preview`）です。設定の点検・自己点検・文字列の確認を補助するもので、ウイルス対策、常時監視、侵入検知、攻撃の自動遮断を行う製品ではありません。

会社の端末で使う前に、情報システム部門の承認を確認してください。Windows設定収集スクリプトは実機未検証・未署名です。一般利用者は実行せず、管理者によるソース確認と承認済み環境での試験を先に行ってください。ブラウザーの点検機能とWindowsの架空結果表示にはスクリプト実行は不要です。

## 配布内容

手順書付きの配布ファイルを、このディレクトリのバージョン別フォルダーに掲載します。配布ファイルの登録・照合が終わった段階で、このページへダウンロードリンクを追加します。

個人情報、社内の点検結果、認証情報を公開Issueに投稿しないでください。第三者認定・完全な安全性・全環境での動作は保証していません。
