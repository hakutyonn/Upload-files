[無料セキュリティ「守りの道具箱」へ戻る](../mamori-toolbox/README.md)

## AIはじめてセット

**初級｜AIの頼み方と、出力の確認から。**

`目的と事実を整理 → AIに頼む → 出力を人が確かめる`

予定する内容は、AIへの頼み方・安全な入力、メールと要約の記入例、プロンプト、音声＋図解のミニ講座、事実確認チェックです。セット全体は編成中です。

### 無料で試す：確認依頼の条件を分ける

次は架空の練習例です。会社の機密情報や実在の個人情報を入れず、組織が認めたAIとルールの範囲で使ってください。

```text
次の架空メモだけを使い、確認依頼のメール案を作成してください。
事実と未確認を分け、担当者名・期限・約束を推測で足さないでください。

目的：手順書の確認を依頼する
事実：手順書の初版を作成した
未確認：確認担当者と確認期限

出力：件名、本文案、送信前に人が確認すること。
実際のメール送信や外部サービスの操作は行わないでください。
```

## Power Automate はじめて構築セット

**初級〜中級｜AIの設計案を、一つのフローにする。**

`環境と権限を確認 → 自分宛て通知を作る → 実行結果を確認 → 停止する`

予定する内容は、通知入門の音声同期講座、設定手順、AIに設計やエラーを相談する文章、テスト表、権限・費用・停止の確認です。

通知入門の音声同期講座1本は作成済みですが、セット全体の品質確認・提供準備は未完了です。この公開リポジトリに有料候補の動画や教材本体は置いていません。

無料で進め方を確認する資料：[Microsoft公式・クラウドフローの開始方法](https://learn.microsoft.com/ja-jp/power-automate/get-started-with-cloud-flows)

## Copilot Studio はじめて構築セット

**初級〜中級｜回答の範囲を決め、架空FAQから試す。**

`答える範囲を決める → 資料を用意 → 回答と回答できない質問をテスト → 公開前確認`

予定する内容は、FAQ設計、AIに設計・指示文を相談するテンプレート、画面手順、音声同期講座、架空FAQ、テスト質問、認証・共有・公開前チェックです。セット教材は制作前の構成案です。

### 無料で考える：答えない場合も決める

架空の資料には「練習室は平日9:00〜17:00」とだけ書いてあります。

「何時まで使えますか？」には資料の時間を回答します。「明日の予約を取って」「社内規程を教えて」には、この資料からは判断・実行できないと案内します。これは説明例で、実際のAIや予約処理は動作していません。

無料で進め方を確認する資料：[Microsoft公式・エージェントの作成とテスト](https://learn.microsoft.com/ja-jp/microsoft-copilot-studio/fundamentals-get-started)

## AI × 自動化 ステップアップセット

**中級｜基礎を作れた後に、連携と運用へ。**

`受付 → 回答できるか確認 → 回答または人へ引き継ぐ → 結果を記録`

予定する内容は、Power AutomateとCopilot Studioの役割分担、連携演習、重複・権限・例外・再実行の確認、引き継ぎ資料です。連携演習・音声講座は制作予定です。

## 購入前に確認すること

教材と、Microsoftなどの製品利用契約は別です。利用環境・ライセンス・作成権限・接続先の制限を先に確認してください。環境が分からない場合は、購入より先に無料の説明例や公式資料で学習の順番を確認します。

**個別相談・個別サポート・導入代行は含まれません。** 購入者が自分で進める教材の予定です。通常の自習と、別売りの人的な相談・導入サービスは分けます。商品未着や製品不良などの取引対応まで拒む意味ではありません。

利用人数・社内共有範囲・価格は、正式な販売条件を確定してから表示します。無料セキュリティには、有料教材の人数条件を適用しません。
