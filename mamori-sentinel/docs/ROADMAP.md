# 開発ロードマップ

- Phase 0（本版）: 指定フォルダーの完全性監視、Windowsの一部イベント、Defender状態、ローカルログと画面
- Phase 1: 低権限のWindowsサービス、停止時の外部監視、通知、署名付き更新、ロールバック、負荷試験
- Phase 2: 影響が限定され可逆な修復だけを許可リスト化。管理者承認、バックアップ、事後検証を必須にする
- Phase 3: 集中管理、mTLS、RBAC、端末登録・失効、テナント分離、SIEM/EDR連携、冗長化、SBOM、第三者診断

ロードマップは実装済みを意味しません。各段階の検証が終わるまで企業本番に適用しません。
