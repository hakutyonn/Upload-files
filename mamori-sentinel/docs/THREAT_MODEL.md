# 脅威モデル・安全設計

## 検知する範囲
- 指定したフォルダーのファイル追加・変更・削除
- Windows Securityログの一部イベントID（4625、1102。権限と環境に依存）
- Microsoft Defenderの一部状態（取得できる環境のみ）

## 対象外
カーネルレベル攻撃、メモリ内マルウェア、ネットワーク全体、メール・DNS、クラウドID、SaaS、ランサムウェアの完全阻止・復号、攻撃者が管理者権限を得た端末の完全な証拠保全。

## 自動修復の境界
このMVPはOS設定・アカウント・サービス・ファイルを自動変更しません。AI出力をコマンドとして実行しません。将来の自動修復は、許可リスト、最小権限、変更前バックアップ、変更後の独立検査、失敗時ロールバック、監査ログ、検証環境での試験を必須とします。

## データ
既定はローカル記録のみ。外部AI、メール、Webhookへの自動送信なし。ダッシュボードは127.0.0.1のみで待ち受けます。AI説明は手動実行時のみ、パスや生ログを省いてlocalhostのOllamaに渡します。
