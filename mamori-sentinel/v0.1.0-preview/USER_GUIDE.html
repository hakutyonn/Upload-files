仕組み

最初の3ステップ

① 展開・設定

ZIPを展開し、config/config.json の監視先がテスト用フォルダーか確認。

② 基準を作成
python .\src\mamori_guardian.py --init-baseline

基準作成は既存ファイルを上書きしません。

③ 1回実行
python .\src\mamori_guardian.py --once

ログと検知結果を確認後、継続実行を試します。

ローカル画面

python .\src\dashboard.py

同じPCで http://127.0.0.1:8765 を開きます。外部ネットワークには公開しません。

異常が出たら

  1. 時刻・対象を確認。
  2. 予定された変更か管理者に確認。
  3. 不明なら既存のEDR・インシデント対応手順を優先。
  4. このツールからファイル削除や保護設定変更をしない。
